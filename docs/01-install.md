# 安装与首次连接

## 1. 确认适用环境

| 项目 | 条件 |
| --- | --- |
| Mac | Apple Silicon，macOS 26+；当前实测 macOS 27 |
| 路由器 | 当前实测小米 AX3000 RA80，原厂 1.0.58，Linux 4.4.60 |
| 接入方式 | Mac 连接路由器主 Wi‑Fi，或普通内网 LAN 口 |
| 管理权限 | 你自己的路由器已有可用 SSH 登录 |
| 认证组件 | 已安装 MentoHUST 和兼容控制脚本，见 [部署前提](02-router-preparation.md) |

**路由器 SSH 密码、Wi‑Fi 密码、校园网密码是三种不同凭据。** App 的连接设置需要路由器 SSH 密码；认证管理页面才填写校园网账号。

## 2. 获取 App

优先按照 [源码构建教程](06-development.md) 在自己的 Mac 上编译。本仓库的 `dist/` 产物不进 Git；公开分发的 ZIP 如已提供，应使用仓库 Releases 页面中的正式资产，不使用聊天中的临时或个人路径。

打开 `MentoGlass.app`。编译后的 App 不依赖 Python、浏览器或本地 HTTP 服务。若系统因开发者身份或公证状态阻止打开，先确认来源和文件完整性，再按照 [Apple 官方安全打开 App 的说明](https://support.apple.com/102445)处理；项目不要求关闭 Gatekeeper 或批量移除隔离属性。

## 3. 建立连接

1. 确保 Mac 连接路由器**主 Wi‑Fi**。访客 Wi‑Fi 或手机热点通常不能访问内网管理地址。
2. 打开「连接设置」。
3. 填写地址，例如默认 `192.168.31.1`；若你改过 LAN 地址，填写自己的实际地址。
4. SSH 端口默认 `22`，用户名填写已有管理账号；原有部署通常为 `root`。
5. 输入自己的路由器 SSH 密码。仓库不提供默认密码。
6. 如希望下次自动连接，勾选「将 SSH 密码保存到这台 Mac 的钥匙串」；否则仅本次使用。
7. 点击「连接并读取状态」。成功后检查认证进程、WAN 地址和最近刷新时间。

首次 SSH 连接采用首次信任记录主机公钥。记录位置为 `~/Library/Application Support/MentoGlass/known_hosts`。后续身份改变会拒绝连接；首次连接前应确认管理地址确实是自己的路由器。

## 4. 区分管理连接与外网

校园网断开时，路由器主 Wi‑Fi 和本地 SSH 仍可能正常，通常可以继续在 App 中重新认证，无需先给电脑接网线。

「进程运行」只表示本地程序存在。「外网可用」是你手动检测时的结果，界面显示其时间；两者不能互相替代。如果路由器页面可打开而 App 连接失败，按 [SSH 排查步骤](07-troubleshooting.md)处理。
