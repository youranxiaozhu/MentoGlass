# 日常操作教程

## 1. 读取与检测

连接后先查看「概览」中的进程、守护、WAN 地址和更新时间。点击「检测外网」时，路由器会对预设公共地址做少量 ICMP 请求，并对一个公共域名做 DNS 查询；不进行速度测试。ICMP 可能被网络过滤，因此检测失败需结合认证日志判断。

可在「连接设置」选择每 30 秒刷新状态。它读取本地状态，不自动重启认证；App 不在前台时不继续该刷新。

## 2. 断网后的处理顺序

1. 保持连接路由器主 Wi‑Fi。
2. 刷新状态，检查 WAN 是否有地址、线路是否插好。
3. 到「运行日志」读取最新认证错误，注意日志时间。
4. 确认是自己的账号且允许接入后，点击一次「重新认证」。
5. 等待返回结果，再检测外网；不要连续反复点击认证。

上游停网、账号限制、网口断开、学校 DHCP 故障都可能无法通过重新认证解决。见 [故障排查](07-troubleshooting.md)。

## 3. 修改账号与密码

在「认证管理」修改第一账号。密码框留空表示保留路由器原密码；输入新密码后保存配置，再按需正常重新认证。保存前会备份为 `/data/mentohust/mentohust.conf.mentoglass-backup`，每次保存都会更新这份备份。

不要在 SSH 地址栏填写校园网账号；两类登录目的不同。保存配置不会直接重启当前认证。

## 4. 显示已保存密码

点击「显示密码」才读取已保存密码；再次点击隐藏。页面切换、窗口关闭或 30 秒到期会自动隐藏。

校园密码不写进 Mac 钥匙串、偏好设置或导出日志；SSH 密码则可由用户选择保存到钥匙串。路由器上的 `EncodePass` 是可还原编码，**不等于强加密**，所以文件权限和路由器访问权限仍很重要。

## 5. 定时重新认证

1. 打开「认证管理」。
2. 选择每 24、48、72 小时或每 7 天。
3. 打开「定时重新认证」。开启或修改间隔从当前时间重新计时，不立即断开认证。
4. 刷新查看下一次时间、最近执行结果。

路由器每分钟检查一次是否到期，执行可能有约一分钟偏差。时间保存在 `/data/mentohust/mentoglass-schedule-*`，原有 cron 任务会保留。断电、时钟无效、WAN 未连接、守护关闭或旧进程无法正常退出时会跳过；错过多个周期不会密集补发。

这项功能只作用于第一账号，第二账号不随之定时重启；它不是持续互联网健康检测或实时断网重连。初次安装默认关闭，是否开启由你选择。

## 6. 停止与守护

- 「关闭守护」不停止当前进程，但后续不由守护拉起。
- 「停止认证」同时关闭定时认证与守护，并停止认证，避免立即重启。
- 「启动认证」会打开守护并尝试一次普通启动。

定时开关的关闭只取消计划，不停止当前认证。关闭 App 也不停止路由器上已运行的服务。
