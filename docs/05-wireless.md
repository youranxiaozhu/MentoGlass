# 无线带宽与国家／地区

## 1. 160MHz 的实际含义

「固定 160MHz」操作只适用于已经实际运行 160MHz 的本项目 QCA／CN 部署。它保存 `bw=160` 与 `htmode=HT160`，备份旧无线配置，保留信道和区域；不为切换带宽重启无线。

它不会强制所有手机、电脑都使用 160MHz。终端能力、信号、干扰和合法雷达避让都会影响实际带宽。其他型号、未运行 160MHz 或地区不符合时，操作会拒绝，而不是尝试绕过驱动。

## 2. 为什么信道 44 仍可能等待

160MHz 是整个宽信道，不仅是界面上的主信道。常用 36–64 组合包含 5250–5350MHz，因此主信道 44 也不能免除整个宽信道的 DFS 检测。中国对该范围要求动态频率选择，且不得提供关闭 DFS 的选项。[工信部规定](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2021/art_e4ae71252eab42928daf0ea620976e4e.html)

若更重视减少雷达等待，可以考虑固件支持的当地合法非 DFS 信道与 80MHz；保留 160MHz 时，仍可能遇到正常检测等待或避让。项目没有删除等待时间的功能。

AX3000 RA80 只具备 2.4GHz 和 5GHz 射频硬件，不能通过改区域开启 6GHz。[小米规格](https://www.mi.com/sg/product/xiaomi-mesh-system-ax3000/specs/)

## 3. 选择区域

1. 到「连接设置」找到「无线国家／地区」。
2. 查看 2.4GHz、5GHz 的**实际驱动区域**与保存区域。
3. 按设备实际使用地点选择区域。当前列表有 24 个常用地区，未承诺此 RA80 对所有选项都能维持相同信道或带宽。
4. 点击「保存区域」。这一步更新配置，不立刻重启无线。
5. 核对无误后点击「重启无线并应用」，在 App 提示中确认。Wi‑Fi 会短暂断开，DFS 信道可能额外等待。
6. 重新连接主 Wi‑Fi，刷新状态，确认实际区域和应用结果。

本固件的高通驱动读数比全局 `iw reg get` 更适合确认实际区域。实测 CN 对应驱动 ID 156；内核全局显示 00 不代表可以忽略地区要求。

## 4. 备份和恢复

组件保存在 `/data/mentoglass-wireless/region.sh`，旧配置备份为该目录下的 `wireless-before-region.conf`。目录 0700，备份 0600。

组件使用原厂无线专用 `/sbin/wifi reload_legacy`，避免通用网络重载影响独立双线路。配置未被其他操作修改且应用失败时，组件恢复旧配置并尝试一次无线重载；若检测到其他操作修改了配置，则保留修改并报告冲突。

自动回退也依赖固件能正常重载无线，不能保证任何故障都可自动恢复。无线断开期间不要重复应用；等待后先重新连接并读取状态。改地区不是提高校园网账号或物理入口带宽的手段。
