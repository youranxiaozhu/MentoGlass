# 验证范围与已知限制

## 验证基线

2026 年 10 月 1–2 日在特定 RA80 部署完成原生 App 与双线路验证，最终版本 1.3.1。下面记录历史验收范围，**不是对当前任何路由器状态的实时保证**。

| 范围 | 验证结果 |
| --- | --- |
| Mac | macOS 27、Apple Silicon 上打开原生界面与读取真实状态 |
| 包 | ZIP 解压后严格签名核验、自检；App 与源码内置脚本一致 |
| 管理 | 主 Wi‑Fi 下 SSH 可管理，不要求校园网已联网 |
| 密码 | 两账号按需显示／隐藏，编码解码通过，验收不输出内容 |
| 定时 | 本地模拟到期、关闭、时钟异常、锁恢复、跳过和不补发 |
| 双线路 | 两个合法授权账号独立配置／进程／租约与策略表 |
| 分流 | 正常用户连接分别经过两个出口；单连接不聚合 |
| NSS | 被动连接记录确认两条出口都有正确加速路径 |
| 160MHz | 实际运行 `11AHE160`；保留 CN 与 DFS |
| 区域 | 实机读取 CN／驱动 ID 156；重复保存 CN 不重载无线 |
| 稳定性 | 12 项离线双线路测试；安装前后认证进程、账号、无线配置及主路由不变 |

## 没有完成的实机测试

- 实际拔掉校园网线后的切换与恢复。
- 实际强制 DHCP 租约变化、完整租约周期与真实路由更新。
- 重启路由器后的全套恢复和长期多设备并发。
- 等待完整 24 小时后真实定时认证。
- 在此设备应用其他国家区域，或真实失败后的无线恢复。
- 测速与压测；因此没有实测“网速翻倍”的承诺。

离线测试使用替身命令和假数据，不接触校园网。历史实机检查只进行授权设备管理、普通认证、少量正常连通请求和被动状态读取，没有扫描、攻击或认证洪泛。

## 1.3.1 的修复

第一线路检查真实 `switch1` 端口 4，避免 CPU-facing `eth0` 始终在线造成误判。策略表 201 更新使用互斥，先安装当前路由再删除旧前缀／优先级；DHCP 并发变化时推迟删除。两个校园接口对称设置 `arp_ignore=1`、`arp_announce=2`，不改变全局与私有 LAN 设置。

维护仍每分钟执行，仍不属于端到端健康探测。既有坏连接不会被自动搬迁，学校上游故障也可能在本地状态全部正常时发生。
